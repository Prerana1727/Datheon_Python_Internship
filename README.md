
# Datheon Python Programming Internship

This repository contains three Python projects developed as part of the Datheon Python Programming Internship.

## Projects

### 1. Hangman Word Guessing Game
- Console-based word guessing game.
- Random word selection.
- Six incorrect attempts allowed.
- ASCII Hangman drawing.
- Tracks previously guessed letters.
- Prevents duplicate guesses.

**Technologies:** Python, Random Module, Sets, Loops, Functions.

### 2. Interactive Terminal Chatbot
- Rule-based conversational chatbot.
- Recognizes different user intents.
- Provides responses about business hours, products, pricing and contact details.
- Uses regular expressions for keyword matching.
- Supports exit commands.

**Technologies:** Python, Dictionaries, Functions, Regular Expressions.

### 3. Automated File Organizer
- Automatically organizes files based on extensions.
- Creates category folders.
- Moves files into appropriate folders.
- Handles duplicate filenames.
- Includes error handling and execution summary.

**Technologies:** Python, OS Operations, Shutil, Pathlib, File Handling.

## Requirements

- Python 3
- Visual Studio Code (or any Python IDE)

## How to Run

Clone this repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Open the project folder in VS Code.

Run individual projects:

```bash
python hangman.py
```

```bash
python chatbot.py
```

```bash
python organizer.py
```
